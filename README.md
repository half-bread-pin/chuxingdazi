# 我的出行搭子 (chuxingdazi)

一个**本地优先**的 Android 出行规划 App：私人地点簿 + 行程时间轴 + 路线规划与导航，所有数据只保存在手机里。

## 一、应用功能

- **私人地点簿**：把生活/旅途中在意的地方标记成自己的点位，按分类(内置 7 类 + 自定义分类，98 个矢量图标，可任意自定义)和清单组织；支持地图选点、搜索入库、按分类/地区/清单筛选。
- **行程规划**：把点位安排到某天某小时，支持跨天段、重叠分列、拖拽调整时间；未安排的点位留在待安排池。
- **路线规划**：任意起终点/途经点，按驾车/步行/骑行/公交算路，多方案对比，分段详情预览。
- **导航**：驾车/步行/骑行可**应用内导航**(腾讯导航 SDK)，也可一键跳转到百度/高德/腾讯地图 App；公交通过跳转地图 App 实现。
- **数据自持**：备份导出为单个 JSON 文件，导入可增量合并，换机/多机之间自己搬数据。
- **无服务器**：所有业务数据存在 App 私有目录，唯一联网用途是地图 SDK 的底图/检索/算路/导航请求；无统计、无广告。

## 二、从 APK 使用

不想搭建开发环境的用户，直接安装打包好的 APK 即可使用，功能与源码构建版一致。

**下载与安装**

- 在本仓库的 **Releases** 页面下载 APK 文件(约 168MB，通用包:arm64 / armeabi-v7a 真机均可安装；x86_64 模拟器可安装，但导航/定位的 native 库仅含 arm 架构，这两项在模拟器上不可用)。
- 系统要求:Android 7.0 及以上。
- 下载后直接打开安装，系统提示"禁止安装未知应用"时按引导允许即可。
- 项目发布的 Release 使用同一签名证书，后续新版本可直接覆盖安装，本地数据(点位/行程/清单)自动保留。

**配置 Key**

- 首次启动同意隐私协议后，按引导在[腾讯位置服务控制台](https://lbs.qq.com/)免费申请你自己的 Key 并填入，不填则地图/搜索/导航不可用。
- 申请时需要绑定以下应用身份(与 Release APK 一致):
  - 包名: `com.visualzyzy.chuxingdazi`
  - 发布证书 SHA-1 指纹: `565a9060563a2709e4976e2a57a8ac043230bdac`
- Key 属于你自己的账号，不随 APK 分发；后续可在 App 设置页随时更换。

## 三、从源码使用

**环境要求**

- Android Studio Hedgehog(2023.1.1)或更高版本
- JDK 17(在 Studio 的 Gradle 设置中指定；本项目编译目标即 17，本地实测 Eclipse Temurin 17 可用)
- Android SDK Platform 34(首次 Gradle 同步时 Studio 会提示自动安装)
- Gradle 8.7 / AGP 8.2.2:版本已在项目中固定，无需手动安装； **开发时，曾使用AGP8.5，与腾讯导航 SDK 存在已知兼容缺陷(R 类生成错误，构建失败)**
- 测试设备:Android 7.0 及以上(minSdk 24)； **建议真机**——导航 SDK 带定位防作弊机制，模拟器的模拟定位可能被拒绝(表现为导航时提示"信号弱")

**构建步骤**

1. 克隆本仓库后，用 Android Studio 打开项目根目录，等待 Gradle 同步完成。
2. 所有依赖由 Gradle 自动拉取(含腾讯导航 SDK，官方 maven 坐标)；首次同步需联网，国内走阿里云镜像加速。
3. 地图能力基于[腾讯位置服务](https://lbs.qq.com/)，**使用前需在该控制台免费申请自己的 Key**，并在 App 首次启动的初始化引导或设置页面填入(填写 Key 后才可使用地图/检索/导航功能)。Key 绑定你自己的应用身份，不随仓库分发。


**打包与签名**

- Debug 构建无需签名配置，直接可跑。
- Release 构建需自备 keystore:在项目根目录创建 `keystore/keystore.properties` 并填入 `storeFile`、`storePassword`、`keyAlias`、`keyPassword` 四项(该目录已被 `.gitignore` 排除，不要提交进仓库)。
